# 🔗 URL Shrinker

URL Shrinker is a simple and efficient web application that converts long URLs into short, shareable links.  
It also tracks the number of times each shortened link is accessed.

---

## 🚀 Features

- Shorten long URLs instantly
- Redirect users using short links
- Track click counts for each URL
- Clean and responsive UI using Bootstrap
- Simple and fast performance

---

## 🛠️ Tech Stack

- **Frontend:** HTML, Bootstrap 4
- **Backend:** Node.js, Express.js
- **Template Engine:** EJS
- **Database:** MongoDB
- **Icons:** Font Awesome
